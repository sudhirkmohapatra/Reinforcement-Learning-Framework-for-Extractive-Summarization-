AREX-NET is a hybrid deep learning framework for extractive single-document text summarization designed to address the growing need for efficiently summarizing large volumes of unstructured text data. The model integrates a Bi-Directional Long Short-Term Memory (BiLSTM) encoder with a contextual attention mechanism and reinforcement learning-based optimization to enhance summary quality. The pipeline includes comprehensive preprocessing steps such as text normalization, contraction expansion, noise removal, sentence segmentation, subword tokenization, and feature extraction (POS tagging, dependency relations, and Named Entity Recognition). The model is initially trained using supervised learning and later fine-tuned with reinforcement learning, where sentence selection is treated as a sequential decision-making process guided by a ROUGE-L-based reward function. Experimental results demonstrate that AREX-NET outperforms existing baseline models in terms of ROUGE, BLEU, METEOR, and BERTScore, producing coherent, concise, and contextually rich summaries.
